== BPF/ifnet Contract Hardening: D59140

*Contact:* Luis Castellanos <ing.castellanosdz@gmail.com>

=== Description

During Q3 2026, a review of the `bpf_movein()` path in `sys/net/bpf.c`
was conducted following an observed failure when writing to a BPF descriptor
on `lo0` (FreeBSD 14.4-RELEASE-p8).

The initial observation was a write(2) returning `EAFNOSUPPORT` when
sending a packet through a BPF descriptor bound to `lo0` (DLT_NULL).
The original attribution — missing `sa_len` initialization in `if_output`
drivers — was not sustained after independent review by Gleb Smirnoff
(FreeBSD committer).

Review established that the reproducer violated the DLT_NULL contract:
a write(2) on a BPF descriptor must prepend a 32-bit word in host byte
order containing the address family. The `sa_len` check proposed in the
individual drivers (`if_disc.c`, `if_gif.c`, `if_loop.c`, `if_me.c`,
`if_tuntap.c`) is not required because the existing BPF/ifnet interface contract
is already defined at the BPF boundary in `bpf_movein()`.

Following that review, D59140 was updated to add a defensive assertion
in `bpf_movein()` per Gleb's suggestion:

[source,c]
----
MPASS(hlen <= sizeof(sockp->sa_data));
----

This makes the existing BPF/ifnet contract explicit through a defensive
assertion at the point where the contract is consumed. The assertion
protects the `sa_data` bounds invariant at the point where the
computed header length is consumed.

=== Work Completed

* Identified and reproduced `EAFNOSUPPORT` on `lo0` with BPF write(2)
  on FreeBSD 14.4-RELEASE-p8.
* Submitted D59140 to Phabricator with initial fix targeting five
  `if_output` drivers.
* Received review from Gleb Smirnoff identifying the reproducer defect:
  missing 32-bit DLT_NULL address-family header in the packet.
* Corrected the reproducer and verified locally on FreeBSD 14.5-RELEASE.
* Updated D59140 to replace the driver-level checks with a single
  `MPASS` assertion in `bpf_movein()` (Diff 186596).
* Updated Summary and Test Plan in D59140 to document the complete
  investigation history: observed failure -> initial attribution ->
  independent falsification -> corrected reproducer -> local verification
  -> upstream hardening proposal.
