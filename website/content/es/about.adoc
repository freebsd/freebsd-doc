= Acerca de FreeBSD

== ¿Qué es FreeBSD?

FreeBSD es un sistema operativo el cual está disponible en link:../platforms[multitud de plataformas],
poniendo el acento en las funcionalidades, la velocidad y la estabilidad.
Deriva de BSD, la versión de UNIX(R) creada en la Universidad de California, Berkeley.
Lo desarrolla y mantiene link:{contributors}#staff-committers[una amplia comunidad].

== Funcionalidades de vanguardia

FreeBSD ofrece link:../features[funciones] avanzadas de red, rendimiento, seguridad y compatibilidad que todavía faltan en otros sistemas operativos, incluso en algunos de los mejores sistemas operativos comerciales.

== Soluciones potentes para Internet

FreeBSD es una opción excelente como servidor de internet o de intranet.
Proporciona servicios de red robustos bajo las cargas más exigentes y usa la memoria de forma eficiente para mantener buenos tiempos de respuesta con miles de procesos simultáneos.

== Plataforma embebida avanzada

FreeBSD acerca a los dispositivos y plataformas embebidas las funciones avanzadas de un sistema operativo de red, desde equipos Intel de gama alta hasta plataformas con hardware ARM, PowerPC y MIPS.
Desde equipos dedicados a correo y web hasta routers, servidores NTP y puntos de acceso inalámbricos, fabricantes de todo el mundo utilizan FreeBSD como base de sus productos embebidos.
Además, la licencia de código abierto de Berkeley les permite decidir qué parte de sus cambios locales quieren aportar al proyecto.

== Ejecución de un gran número de aplicaciones

Con más de {numports} bibliotecas y link:../applications[aplicaciones], FreeBSD admite aplicaciones para entornos de escritorio, servidor y dispositivos embebidos.

== Fácil de instalar

FreeBSD se puede instalar desde diversos medios, como CD-ROM, DVD o directamente a través de la red mediante FTP o NFS.
Todo lo que necesita son link:{handbook}bsdinstall[estas instrucciones].

== Contribuir a FreeBSD

Contribuir a FreeBSD es fácil.
Solo tiene que encontrar una parte de FreeBSD que crea que se puede mejorar, hacer esos cambios (con cuidado y de forma limpia) y enviarlos de vuelta al Proyecto mediante un informe de error o a un committer, si conoce a alguno.
Puede ser desde documentación hasta material gráfico o código fuente.
Consulte el artículo link:{contributing}[Contribuir a FreeBSD] para obtener más información.

Aunque no sea programador, hay otras formas de contribuir a FreeBSD.
La https://www.freebsdfoundation.org[FreeBSD Foundation] es una organización sin ánimo de lucro cuyas donaciones directas son totalmente deducibles de impuestos.
Visite la página link:https://freebsdfoundation.org/about-us/contact-us/[Contacte con nosotros] para obtener más información.
