= Политика интернационализации

== Политика

Проект FreeBSD использует список, основанный на ISO 3166, для обозначения стран и регионов мира. Этот список включён в дистрибутивы релизов и отображается на официальном веб-сайте. Проект FreeBSD не поддерживает какую-либо конкретную позицию, и изменения в этом списке должны быть утверждены Основной Командой (Core Team) FreeBSD.
