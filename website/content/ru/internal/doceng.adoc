= Устав команды Doceng FreeBSD

Команда link:../../administration/#t-doceng[подготовки документации FreeBSD] -- doceng@ -- является органом, занимающимся вопросами, связанными с управлением проектом документации FreeBSD.
Основные обязанности этой команды:

* Предоставление одобрения для новых коммиттеров документации.
Документация включает статьи и книги, веб-страницы, справочные страницы, примечания к выпускам и их переводы.
Существует два вида прав на коммит в документацию: право переводчика, ограниченное переводами на конкретный язык, и полное право, которое предоставляется только претендентам, продемонстрировавшим достаточные навыки письменного английского языка.
* Поддержание руководства для начинающих по проекту документации, в котором описываются наилучшие практики для проекта документации FreeBSD.
* Управление процессом выпуска документации (doc/).
Это включает координацию обновлений документации к релизу с различными командами переводчиков, координацию с командой инжиниринга релизов для создания тегов в дереве doc/ в течение цикла выпуска, а также документирование этих процедур.
* Обеспечение актуальности генерируемой документации (PDF, HTML и т.д.) на веб-сайте и FTP-сервере по отношению к версиям документов в Git-дереве.
Это включает обеспечение корректной работы сборки веб-сайта, а также взаимодействие с административной командой для установки всего необходимого программного обеспечения (включая сборочные скрипты) на основном веб-сервере.
* Выполнение роли MAINTAINER (при необходимости) или работа в координации с существующими MAINTAINER'ами для обеспечения исправной работы инструментария документации (DocBook, groff и т.д.).
* Поддержание целостности дерева документации FreeBSD (doc/).
Ввиду публичности этих файлов и документов для внешнего мира, doceng@ оставляет за собой право немедленно откатывать (или исправлять без ожидания ответа от первоначального коммиттера) изменения, которые вводят битые ссылки, нарушают сборку веб-сайта или иным образом ухудшают доступность веб-сайта и документации FreeBSD.
* Назначение и курирование команды веб-мастеров FreeBSD, которая выполняет ежедневное обслуживание веб-серверов проекта совместно с другими командами.

Здесь особо отмечается, что doceng@ *не* является органом разрешения конфликтов для проекта документации FreeBSD.
Обсуждение и достижение консенсуса в списке рассылки freebsd-doc — это то, как проект вёл себя и как предполагается вести себя в будущем.

== Текущий состав

Текущими членами этой команды являются {doceng-members}.

== Новые коммиттеры документации

Новые коммиттеры документации утверждаются doceng@ посредством голосования по электронной почте с двухнедельным периодом ожидания.
Коммитер утверждается, если как минимум один член doceng@ голосует «за», и ни один из членов doceng@ не голосует «против».
Когда предложение о предоставлении права на коммит принимается, doceng@ отправляет письмо-подтверждение наставнику и новому коммиттеру с копией core@ и accounts@.

== Неактивные коммиттеры документации

Коммитеры документации, которые не совершали коммитов в течение 18 месяцев, будут оповещены членом doceng@, и при отсутствии ответа в течение двух недель эти коммиттеры будут автоматически удалены из файла доступа.
В случае отсутствия ответа doceng@ также уведомит core@ о неактивных коммиттерах.
Коммитеры, желающие восстановить свои права, должны будут повторно подать заявку в соответствующий орган.
