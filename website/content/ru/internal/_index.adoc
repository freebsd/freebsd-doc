= Внутренние страницы FreeBSD

На этой странице собраны ссылки на документы, описывающие различные аспекты проекта FreeBSD как такового, если рассматривать его отдельно от исходных текстов системы.

== Проекты

Существуют различные проекты, которые находятся за пределами основного пути разработки. Ряд групп работают на «переднем крае», чтобы расширить возможности FreeBSD в новых направлениях.

Здесь представлен обзор link:{freebsd-releng}[процесса инжиниринга релизов FreeBSD].

А здесь вы найдёте link:../releng/[расписания предстоящих официальных релизов FreeBSD].

== Процедуры

Для того чтобы избежать хаоса в проекте, который распространен по всему миру, необходимы некоторые link:policies[формальные процедуры].

== Люди

Персонал проекта FreeBSD состоит из link:../administration[команд, групп и отдельных лиц] с назначенными ролями и зонами ответственности, а также link:{contributors}#staff-committers[разработчиков]. Перейдя по ссылкам, вы найдёте их список, а также объяснения, кто за что отвечает.

Здесь вы можете прочитать link:hats[политику ограничения сроков полномочий для назначенных ролей] от Основной Группы (Core Team) и некоторые рекомендации от {imp-name} о том, link:working-with-hats[как работать с ролями].

== Ресурсы

Здесь приведён список некоторых link:developer[технических ресурсов для коммиттеров FreeBSD].

Для тех, у кого есть учётные записи в link:machines[основной сети FreeBSD.org], здесь перечислены доступные машинные ресурсы и виды работ, для которых они предназначены.

Вы можете узнать больше link:about[о веб-сервере FreeBSD], включая машину, программное обеспечение, зеркалирование веб-страниц FreeBSD.
