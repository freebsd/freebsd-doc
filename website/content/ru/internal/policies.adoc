= Политики для участников проекта FreeBSD

== *Руководство коммиттера*

link:{committers-guide}[Руководство коммиттера] — это общее руководство для всех новых коммиттеров, включающее как технические детали, так и политики. Что касается последних, см. главы о link:{committers-guide}#conventions[Соглашениях и традициях], link:{committers-guide}#developer.relations[Связях с разработчиками] и link:{committers-guide}#rules[Большом списке правил для коммиттеров FreeBSD].

Оно содержит почти всё, что нужно знать новому коммиттеру проекта FreeBSD. Для получения дополнительной информации см. «Руководство для начинающих по проекту документации» и «Руководство по портам» ниже.
