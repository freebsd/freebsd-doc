=== Перевод fts(3) в Capsicum

Ссылки: +
link:https://man.freebsd.org/cgi/man.cgi?fts(3)[Страница руководства fts(3)] URL: link:https://man.freebsd.org/cgi/man.cgi?fts(3)[]

Контакт: Jitendra Bhati <jitendrabhati2026@gmail.com> +
Контакт: Alan Somers <asomers@FreeBSD.org>

Библиотека обхода каталогов man:fts[3], используемая man:find[1], man:rm[1], man:ls[1], man:chflags[1] и другими утилитами, исторически полагалась на системные вызовы на основе путей, которые не работают в режиме возможностей man:capsicum[4].

В этом квартале fts получила новую точку входа `fts_openat()`, принимающую предварительно открытый дескриптор каталога, поле `fts_dirfd` для каждой записи и преобразование её внутренностей в операции относительно файловых дескрипторов, с сохранением совместимости ABI посредством версионирования символов ELF.
Теперь обход может выполняться полностью внутри песочницы Capsicum.

В качестве первого потребителя chflags был переведён в Capsicum для выполнения своей работы через `chflagsat()` над дескрипторами, открытыми до входа в режим возможностей, что ограничивает его иерархиями, указанными в его командной строке.

Эта работа была выполнена в рамках проекта Google Summer of Code 2026.

Спонсор: Google Summer of Code 2026
