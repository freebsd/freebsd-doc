== Краткое описание

Нативный порт FreeBSD, package:www/brave[], доступен в {repo}[оверлее FreeBSD-Ports].
Он собирает Brave *1.94.120*, основанный на Chromium *152.0.7977.76*, для amd64 и aarch64.
Сборка использует только релизные архивы и инструментарий портов (LLVM 22, Rust, Node 24).
Она не использует depot_tools, gclient, CIPD или siso и не требует Linuxulator.

== Состояние

* Нативная сборка на amd64 и aarch64.
* Списки фильтрации Shields.
* Опции порта для Widevine (через package:www/foreign-cdm[]), PipeWire, Qt6, CUPS, Kerberos, а также ALSA, PulseAudio и sndio.


== Открытые вопросы
* *Ключ служб.* Без него обновления компонентов возвращают 403, поэтому нет каталога блокировки рекламы и нет CRLSet.
  В настоящее время порт использует тот же ключ, который поставляет Arch.
* Leo, Brave Search и распознавание речи не имеют ключей, поэтому они не работают.
* Средство обновления и удалённое управление отключены.
  Обновления поступают через pkg.
* Версия Brave привязана к версии Chromium в package:www/chromium[].
