=== Разработка драйверов FreeBSD для BananaPi R2 / R64 / R2 Pro

Ссылки: +
link:https://wiki.freebsd.org/arm/Bananapi[Banana Pi на вики FreeBSD] URL: link:https://wiki.freebsd.org/arm/Bananapi[]

Контакт: Martin Filla <freebsd@sysctl.cz>

Этот проект добавляет поддержку FreeBSD для трёх роутерных плат Banana Pi:
BPI-R2 (MediaTek MT7623, armv7), BPI-R64 (MediaTek MT7622, arm64) и
BPI-R2 Pro (Rockchip RK3568, arm64).

==== Введение в BPI-R2 (MT7623)

Banana Pi BPI-R2 — это роутерная плата на базе MediaTek MT7623N (четырёхъядерный
ARM Cortex-A7, до 1,3 ГГц) с 2 ГБ DDR3, 8 ГБ eMMC, 4x Gigabit LAN и
1x Gigabit WAN, управляемыми встроенным коммутатором MT7530, двумя портами SATA, двумя
портами USB 3.0, слотом mini PCIe, выходом HDMI, разъёмами MIPI DSI/CSI и
обычными разъёмами UART, I2C, SPI, PWM и GPIO.  Поскольку MT7623 — это
armv7-компонент, это единственная из трёх плат, которая собирается из
32-битной конфигурации ядра `GENERIC`.

==== Текущее состояние поддержки FreeBSD BPI-R2

На данный момент реализовано:

* Поддержка платформы / machdep — карта устройств, ранняя консоль, поздняя инициализация и
  сброс SoC, а также опция ядра `SOC_MEDIATEK` и сборка DTB для
  `mt7623n-bananapi-bpi-r2.dts`
* Запуск SMP для четырёх ядер Cortex-A7
* Драйвер UART
* Управление тактированием — общая инфраструктура тактирования MediaTek (гейты, мультиплексоры,
  фиксированные делители), используемая контроллерами тактирования topckgen, infracfg, pericfg, hifsys, bdpsys,
  imgsys, vdecsys и audsys
* Тактовые генераторы PLL (apmixedsys)
* Регистры конфигурации системы (syscfg/syscon)
* Pinctrl
* GPIO

==== План разработки BPI-R2

Реализовать недостающие драйверы:

* Контроллер хранилища (eMMC/SD/MMC)
* Ethernet (GMAC) и коммутатор MT7530
* USB 3.0 (xHCI) и T-PHY
* SATA / AHCI
* PCIe
* Сторожевой таймер
* I2C
* SPI
* PWM

==== Введение в BPI-R64

Banana Pi BPI-R64 — это отладочная плата на базе MediaTek MT7622
(двухъядерный ARM Cortex-A53, ~1,35 ГГц) с 4x Gigabit LAN, 1x Gigabit
WAN, 802.11n 4x4 Wi-Fi, Bluetooth 5.0 и рядом периферийных интерфейсов
(UART, SPI, I2C, GPIO, SATA, mini PCIe, eMMC и другие).

==== Текущее состояние поддержки FreeBSD BPI-R64

На данный момент реализовано:

* Драйвер UART
* Управление тактированием (clocks)
* Pinctrl
* Контроллер хранилища (eMMC/SD/MMC)
* Драйвер Ethernet для GMAC MT7622
* Драйвер USB 3.0 (xHCI)
* T-PHY (PHY для USB и PCIe)
* Драйвер сторожевого таймера
* Драйвер RTC
* Драйвер генератора случайных чисел
* Драйвер конфигурационного пространства PCIe (pciecfg)
* sysirq — контроллер полярности прерываний
* PCIe — экспериментально
* Wi-Fi — экспериментально

==== План разработки BPI-R64

Реализовать недостающие драйверы:

* SATA / AHCI, включая режим SATA для T-PHY
* GPIO
* I2C
* SPI
* PWM

Ведутся работы:

* Рецензирование и переработка драйверов тактирования
* Коммутатор Ethernet MT7531

==== Введение в BPI-R2 Pro

Banana Pi BPI-R2 Pro — это следующее поколение отладочной платы умного роутера,
построенной на процессоре Rockchip RK3568.  Она несёт 2 ГБ памяти LPDDR4
и 16 ГБ хранилища eMMC, а также предлагает два порта USB 3.0, пять портов Gigabit
Ethernet, слот M.2 Key-E и слот mini PCIe, два интерфейса MIPI DSI
(один из которых можно программно переключить на LVDS), один интерфейс камеры MIPI CSI
и один выход HDMI.

==== Текущее состояние поддержки FreeBSD BPI-R2 Pro

На данный момент реализовано:

* Драйвер UART
* Управление тактированием (clocks)
* Pinctrl
* GPIO
* Контроллер хранилища (eMMC/SD/MMC)
* Драйвер USB 3.0 (xHCI)
* Драйвер сторожевого таймера
* Драйвер PCIe

==== План разработки BPI-R2 Pro

Реализовать недостающие драйверы:

* HDMI
* MIPI DSI/CSI

Ведутся работы:

* AHCI / SATA
* PCIe
