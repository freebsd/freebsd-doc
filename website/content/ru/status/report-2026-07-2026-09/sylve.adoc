=== Sylve — унифицированная платформа управления системой для FreeBSD

Контакт: Hayzam Sherif <hayzam@alchemilla.io>

Sylve — это современная унифицированная платформа управления системой для FreeBSD.
Она предоставляет интегрированный веб-интерфейс для управления виртуальными машинами (через Bhyve), джейлами, сетью вокруг них и хранилищем ZFS.

Бэкенд реализован на Go, а фронтенд построен на Svelte.
Проект делает упор на минимальный системный след.
По умолчанию он не требует каких-либо пакетов вне базовой системы.

Необязательные зависимости среды выполнения, требуемые только при использовании соответствующих функций, включают:

- package:devel/libvirt[] для виртуализации
- package:devel/qemu[devel/qemu-tools] для управления образами дисков
- Samba 4.x (например, package:net/samba424[]) для обмена файлами по SMB
- package:sysutils/swtpm[] для поддержки эмуляции TPM
- package:dns/dnsmasq[] для служб DHCP и DNS

Порт подтягивает эти зависимости для удобства пользователя, но сам по себе Sylve не требует зависимостей для работы.

==== Основные достижения третьего квартала

В этом квартале мы опубликовали два помеченных выпуска: v0.3.0 24 августа, который включил работу по сети, миграции, репликации и резервному копированию, о которой сообщалось в прошлом квартале, и v0.3.1 7 сентября, последний улучшил восстановление кластера, резервное копирование, миграцию и управление хранилищем гостей.

===== Центр обработки данных / Кластер

* Миграция между узлами кластера теперь передаёт основную часть данных ZFS, пока рабочая нагрузка ещё онлайн, с последующей финальной инкрементальной передачей и защищённым переключением.
* Резервные копии теперь фиксируют связанные наборы данных и диски виртуальных машин как согласованные поколения, с более надёжными рабочими процессами восстановления.

===== Хранилище

* Добавлена более глубокая телеметрия ZFS и ARC, а также запланированные тесты S.M.A.R.T.
* Рабочие процессы хранилища виртуальных машин были переработаны в v0.3.1 с явной семантикой извлечения и удаления подключений.

===== Эксплуатация

* Добавлены защищённый локальный CLI и интерактивная консоль для общих операций с виртуальными машинами, джейлами, сетью и жизненным циклом.
* Встроено управление сертификатами и динамическим DNS, включая бесплатные имена хостов Sylve.app с управляемым TLS, а также поддержку Cloudflare и Namecheap.

===== Общее

* Пользовательская документация была значительно переработана, с ориентированными на задачи руководствами по всем основным функциям.
* Sylve теперь требует libvirt 12.5.0 или новее для управления виртуальными машинами; по-прежнему требуется FreeBSD 15.0 или новее.

===== Обновление дорожной карты

FreeBSD Foundation расширила свою поддержку Sylve новым грантом на части следующего этапа платформы.

Следующий квартал(ы) принесёт:

* Нативное управление контейнерами OCI через Podman.
* Галерею приложений с шаблонами для развёртывания приложений в джейлах и контейнерах.
* Общий доступ по NFS и автоматическую настройку наборов данных ZFS.
* Мобильное приложение для управления кластерами, обновления операционной системы из интерфейса и расписания очистки ZFS.
* Сквозное тестирование и более понятную документацию по миграции.
* Упрощённый интерфейс для начинающих.
