=== Графический интерфейс управления bhyve, написанный на Freepascal/Lazarus

Ссылки: +
link:https://github.com/alonsobsd/bhyvemgr[Bhyvemgr] URL: link:https://github.com/alonsobsd/bhyvemgr/[] +
link:https://github.com/alonsobsd/bhyvemgrd[Bhyvemgrd] URL: link:https://github.com/alonsobsd/bhyvemgrd/[] +

Контакт: José Alonso Cárdenas Márquez <acm@FreeBSD.org>

Bhyvemgr — это графический интерфейс управления bhyve, написанный на Freepascal/Lazarus во FreeBSD.
Ему требуется набор инструментов, большинство из которых установлено в базовой системе, а некоторые устанавливаются из портов/пакетов.
Основная цель — быть настольным приложением, ориентированным на пользователей настольных систем, чтобы легко и быстро настраивать и запускать виртуальные машины на хостах FreeBSD.

Начиная с версии v2.0.0, bhyvemgr был переведён на клиент-серверную архитектуру.
В результате был разработан серверный компонент.
Этот новый компонент называется bhyvemgrd.

Bhyvemgrd поддерживает два способа выполнения привилегированных задач: mac_do/mdo (FreeBSD >= 140000) и mac_do/setcred/exec_paths (только для FreeBSD >= 1501501).
Сам процесс выполняется под непривилегированным пользователем bhyvemgrd.

За последние два квартала было внесено множество исправлений ошибок и улучшений в Bhyvemgr.

Вот некоторые из основных добавленных возможностей:

- Добавлены новые опции операционной системы
- Добавлена поддержка использования VNC unix-сокета (vnc.sock), когда FreeBSD >= 1500509
- Добавлена поддержка снимков хранилища (только если включён zfs)
- Улучшена поддержка TPM
- Переход на клиент-серверную архитектуру (unixsocket, json и т. д.). Bhyvemgr остаётся клиентом, а новое приложение bhyvemgrd используется как сервер.
- Удалены привилегированные функции/процедуры. Теперь они являются частью bhyvemgrd.
- Удалена поддержка sudo/doas.
  Она больше не нужна, поскольку привилегированные задачи будут запускаться из службы bhyvemgrd.
- Удалена поддержка FreeBSD 13.x
- Поддержка remote-viewer (virt-viewer) заменена на vncviewer (tigervnc-viewer).
  vncviewer требует меньше зависимостей и может быть легче, чем вариант virt.
- Прочие исправления, улучшения и изменения

Bhyvemgr и Bhyvemgrd поддерживают aarch64 с 15.x до 16-CURRENT и amd64 с FreeBSD 14.x до 16-CURRENT.
Bhyvemgr можно скомпилировать или установить из package:sysutils/bhyvemgr[] с поддержкой интерфейса gtk2, qt5 или qt6.
Bhyvemgrd можно скомпилировать или установить из package:sysutils/bhyvemgrd[].

Люди, заинтересованные в помощи или поддержке проектов, приглашаются.

Текущая версия bhyvemgr: 2.1.0
Текущая версия bhyvemgrd: 1.2.0
