Dockerbox — это виртуализированный демон Docker.
Хотя демон Docker изначально недоступен во FreeBSD, Dockerbox запускает его внутри виртуальной машины Debian Bhyve, чтобы обеспечить к нему доступ.

==== Обновления состояния

* Dockerbox теперь поддерживает 2 вида нижележащего совместного использования файлов для bind-монтирований: virtio-9p, NFS +
Оба способа предоставляют пути хоста внутрь гостя dockerbox. +
Для путей на хосте bind-монтировать можно только пути, предоставленные в dockerbox.

* Dockerbox теперь поддерживает публикацию порта на настраиваемый IP-адрес привязки хоста +
Раньше поддерживалась только привязка к `0.0.0.0`. +
Это связано с тем, что dockerbox, как гость виртуальной машины, не разделяет IP-адреса хоста. +
Теперь поддерживается привязка только к выбранному IP на хосте с помощью dockerbox-broker. +
Пример использования: `docker run --label dockerbox.bind=192.168.88.100:8080 -p 8080:80 nginx`

* Dockerbox теперь поддерживает настраиваемые IP-адрес и шлюз

* package:sysutils/dockerbox-broker[] теперь присутствует в дереве портов

* Dockerbox-broker теперь поддерживает перенаправление UDP-портов
