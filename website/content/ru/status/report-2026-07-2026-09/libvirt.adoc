=== Улучшение поддержки libvirt для гипервизора bhyve

Ссылки: +
link:https://libvirt.org/drvbhyve.html[libvirt: драйвер Bhyve] URL: link:https://libvirt.org/drvbhyve.html[] +

Контакт: Roman Bogorodskiy <novel@FreeBSD.org>

==== Выполненная работа

* Драйвер libvirt/bhyve:
** Добавлена поддержка конфигурации VLAN, фильтрации VLAN и изолированных портов моста во FreeBSD.
** Добавлена конфигурация порядка загрузки для дисковых устройств.
** Реализовано несколько новых API: переименование домена, управление жизненным циклом, получение информации о госте с помощью QEMU Guest Agent и настройка тайм-аута ответа QEMU Guest Agent.
** Добавлена конфигурация серийного номера для дисков SATA и контроллеров NVMe, а также конфигурация EUI-64 для дисков NVMe.
** Исправлено несколько проблем, связанных с обработкой временных и постоянных доменов, событиями монитора, сообщениями об ошибках при запуске и очисткой устройств TAP.
* В QEMU Guest Agent добавлена поддержка `guest-get-fsinfo` для FreeBSD.
* Расширено покрытие libvirt-tck для libvirt/bhyve.
* Ведётся работа над поддержкой непривилегированного `bhyve:///session`.

==== Планы на следующий квартал

* Завершить поддержку непривилегированного `bhyve:///session`.
* Добавить поддержку устройств TPM.
* Завершить поддержку приостановки/возобновления.
* Продолжить реализацию функций на основе QEMU Guest Agent.
* Продолжить расширение CI и покрыть новые функции на основе guest-agent новыми тестами.
