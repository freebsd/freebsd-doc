=== Расширение поддержки Zoned Storage

Контакт: voidanix <voidanix@FreeBSD.org>

==== Обзор проекта

Работа над этим проектом направлена на расширение поддержки Zoned Storage во FreeBSD путём добавления следующих новых возможностей:

* Новый GEOM-драйвер man:gzoned[8] для эмуляции зонированных устройств.
* Поддержка Zoned Namespaces (ZNS) для зонированных NVMe-накопителей.
* Улучшенная обработка Zoned Storage для man:gconcat[8], man:glabel[8] и man:gpart[8].

Работа выполнялась в рамках Google Summer of Code 2026.

==== Важность для FreeBSD

Новый драйвер man:gzoned[8] эмулирует Zoned Storage поверх обычных, незонированных накопителей, что позволяет разрабатывать, тестировать и интегрировать Zoned Storage без зонированного оборудования.

Поддержка ZNS позволяет использовать Zoned Storage на NVMe SSD.

Zone-aware классы GEOM позволяют использовать управляемые хостом накопители с обычными инструментами хранения.

==== Состояние

man:gzoned[8] теперь находится в main.

Поддержка ZNS была добавлена в драйвер man:nda[4], тогда как поддержка man:nvd[4] не планируется из-за его минималистичной природы.

Управляемые хостом устройства теперь можно объединять через man:gconcat[8], тогда как man:glabel[8] будет аккуратно отказывать им в автоматической маркировке из-за своих требований к метаданным.
man:gpart[8] теперь может создавать схемы разделов GPT на управляемых хостом накопителях, не записывая резервную таблицу GPT.

==== Планы на следующий квартал

* Доработать man:gconcat[8], man:glabel[8] и поддержку ZNS, поскольку теперь они могут полагаться на man:gzoned[8] из main.
* Влить всю работу в main.
