=== Скрипт рабочего стола для bsdinstall

Ссылки: +
link:https://github.com/FreeBSDFoundation/proj-laptop/issues/25[Задача проекта поддержки и удобства использования ноутбуков] URL: link:https://github.com/FreeBSDFoundation/proj-laptop/issues/25[] +
link:https://gitlab.com/alfix/kde-installer-dialogs[Репозиторий проекта] URL: link:https://gitlab.com/alfix/kde-installer-dialogs[]

Контакт: Alfonso S. Siciliano <asiciliano@FreeBSD.org>

Цель этого проекта — предоставить простую функцию в man:bsdinstall[8], установщик системы FreeBSD, для установки и настройки графического окружения.
Установщик должен спрашивать пользователей, хотят ли они установить окружение рабочего стола и, если да, автоматически установить и настроить всё необходимое с минимальным вмешательством пользователя или без него.
После перезагрузки пользователям должен быть показан графический экран входа в систему.

В первом отчёте о состоянии за 2026 год было описано возможное решение: shell-скрипт примерно из 400 строк кода для установки и автоматической настройки компонентов, необходимых для графического окружения рабочего стола, включая драйверы GPU, Xorg, KDE Plasma и SDDM.
После призыва к тестированию, который получил значительное количество отзывов от пользователей, на рассмотрение была подана рецензия D56167 для добавления нового скрипта рабочего стола в bsdinstall.

После подачи рецензии состоялось несколько обсуждений предложенной реализации.
По результатам рецензии было запрошено разделить скрипт на более мелкие компоненты и перенести часть его функциональности в отдельные порты.
Рецензия D56167 теперь устарела.
Затем было проанализировано и протестировано несколько возможных подходов.

Выбранное решение — создание новых портов с вариантами (flavors).

Базовый порт предоставляет инструменты для построения меню и/или возврата скрипту списка пакетов для установки.
Утилиты меню реализованы как shell-скрипты, поскольку разработка API Lua для текстовых пользовательских интерфейсов всё ещё продолжается.

Каждый вариант предоставляет скрипт man:pkg-post-install-lua[5] для настройки пакета, установленного в новой системе.
pkg-post-install-lua был выбран вместо shell-скрипта man:pkg-post-install[5], потому что это облегчит повторное использование кода, если в будущем возникнет необходимость использовать man:pkg-trigger[5].

Следующие четыре новых порта с вариантами, в общей сложности 26 пакетов, были созданы и поданы в Bugzilla:

* x11/bsdinstall-desktop PR298402
  ** Утилиты базового порта: bsdinstall-desktop-checks, bsdinstall-desktop-users с поддержкой меню.
  ** Вариант: -audio.

* graphics/bsdinstall-gpu PR298413
  ** Утилита базового порта: bsdinstall-gpu с поддержкой меню.
  ** Варианты: -amd, -drm, -intel, -nv304, -nv340, -nv390, -nv470, -nv580, -nv595, -nv610, -nvaddons, -nvoptimus, -radeon, -scfb, -vbox, -vesa, -vmware.

* x11/bsdinstall-de PR298442
  ** Утилита базового порта: bsdinstall-de.
  ** Варианты: -kde, -wireplumber.

* x11/bsdinstall-dm PR298455
  ** Утилита базового порта: bsdinstall-dm с поддержкой меню.
  ** Варианты: -ly, -sddm.

В репозитории проекта также завершён новый черновик скрипта рабочего стола.
Он существенно отличается от исходного скрипта и теперь составляет примерно 100 строк кода.
Новая рецензия на добавление скрипта рабочего стола в bsdinstall будет подана после того, как новые порты будут добавлены в коллекцию портов.

Это всё ещё экспериментальная функция.
В будущем, в зависимости от интереса пользователей и отзывов, скрипт рабочего стола можно будет дополнительно улучшить для поддержки дополнительных окружений рабочего стола и графических инструментов.
