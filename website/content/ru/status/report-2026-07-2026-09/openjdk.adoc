=== Улучшение OpenJDK во FreeBSD

Цель этого проекта — улучшить поддержку OpenJDK для FreeBSD/amd64 и FreeBSD/arm64.

Java — важная среда выполнения для многих высокопроизводительных, критически важных корпоративных систем.
Обеспечение корректной и эффективной работы приложений на основе Java во FreeBSD важно для того, чтобы FreeBSD продолжала оставаться жизнеспособной и привлекательной платформой для предприятий, а также компаний и организаций любого размера.

В этом квартале в вышестоящий проект были влиты несколько довольно крупных, инвазивных функций (link:https://openjdk.org/jeps/401[JEP 401: Value Objects] и link:https://openjdk.org/jeps/539[JEP 539: Strict Field Initialization]), из-за чего в этот период было трудно получать рецензии и принятие наших изменений.
Мы потратили время на исправление проблем с BSD-портом, а также на поддержание его в актуальном состоянии по мере появления вышестоящих изменений.

В этом квартале были выполнены следующие исправления/улучшения:

* Различные исправления и улучшения
  - link:https://bugs.freebsd.org/bugzilla/show_bug.cgi?id=296945[Bug 296945]: На бинарных файлах JDK теперь устанавливается ELF-флаг `wxneeded`, что позволяет java работать в системах с включённой защитой +W^X+.
  - link:https://bugs.freebsd.org/bugzilla/show_bug.cgi?id=294358[Bug 294358]: действительно собирать headless без установки библиотек Xorg
  - link:https://reviews.freebsd.org/D58841[Удалён `USE_LDCONFIG` из портов OpenJDK 8 и 11].
    Исправляет link:https://bugs.freebsd.org/bugzilla/show_bug.cgi?id=297282[Bug 297282]: java/openjdk25 — libjava.so не находит libjvm.so
  - Возвращать только символы, соответствующие запрошенному адресу, для man:dladdr[3] в BSD.
    Это также возвращает видимость символов libjvm по умолчанию обратно к скрытой, чтобы избежать раскрытия внутренних символов.
    Это также должно ускорить загрузку библиотеки и снизить потребление ресурсов.
  - link:https://github.com/battleblow/jdk/pull/79[Исправление теста подключения debugd во FreeBSD].
* Вышестоящий BSD-порт:
  - link:https://bugs.openjdk.org/browse/JDK-8390768[Отправлен черновик JEP] для усилий по переводу BSD-порта в вышестоящий проект.
* Порты:

  - OpenJDK 25: link:https://cgit.freebsd.org/ports/commit/?id=2583bd8561d2[Обновлён до версии 25.0.4]
  - OpenJDK 21: link:https://cgit.freebsd.org/ports/commit/?id=a86e7f3b7b3b[Обновлён до версии 21.0.12]
  - OpenJDK 17: link:https://cgit.freebsd.org/ports/commit/?id=ea43accd8d00[Обновлён до версии 17.0.20]
