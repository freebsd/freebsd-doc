=== Поддержка Netlink для туннельных интерфейсов

Контакт: Pouria Mousavizadeh Tehrani <pouria@FreeBSD.org>

Вслед за работой над man:geneve[4] я занимался переносом наших других туннельных драйверов на новый KPI if_clone и добавлением для них поддержки netlink как в ядре, так и в man:ifconfig[8].
Теперь они доступны в CURRENT.

На данный момент я добавил поддержку:

* Поддержка Netlink для man:gif[4] с тестами.
link:https://reviews.freebsd.org/D57666[(D57666)]
* Поддержка Netlink для man:gre[4] с регрессионным тестом.
link:https://reviews.freebsd.org/D55366[(D55366)]
* IFLAF_GROUP — специфичный для FreeBSD атрибут netlink для передачи групп интерфейсов, поскольку IFLA_GROUP работает только с одним числовым идентификатором группы.
man:ifconfig[8] теперь считывает группы интерфейсов из него.
link:https://reviews.freebsd.org/D58643[(D58643)]

Попутно я исправил следующие ошибки:

* Гонки при инициализации модуля man:gre[4] и уничтожении клонированных интерфейсов в джейлах.
link:https://reviews.freebsd.org/D57669[(D57669)]
* Паника в man:vxlan[4] при передаче неиспользуемых значений drvspec.
link:https://reviews.freebsd.org/D58552[(D58552)]
* Неверный перевод имён интерфейсов в дампах Linux netlink под man:linux[4] и сопоставление большего числа типов интерфейсов с ARPHRD.
link:https://reviews.freebsd.org/D59595[(D59595)]

Ведущаяся работа:

* Полная поддержка ключа GRE.
link:https://reviews.freebsd.org/D59849[(D59849)]
