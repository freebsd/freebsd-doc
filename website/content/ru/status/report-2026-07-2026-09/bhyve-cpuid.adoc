=== Полный контроль CPUID для bhyve

Контакт: Hans Rosenfeld <rosenfeld@grumpf.hope-2000.org>

==== Обзор проекта

Текущая работа над этим проектом направлена на интеграцию существующей концептуальной проработки в FreeBSD и на добавление следующих функций удобства использования:

- удобный для пользователя метод конфигурации для переопределения отдельных битов, частей или даже целых функций CPUID по мере необходимости, сохраняя при этом остальную информацию CPUID хост-системы или предопределённую конфигурацию CPUID
- удобный для пользователя метод конфигурации для подписи гипервизора, сообщаемой bhyve
- набор предопределённых конфигураций CPUID на основе общих уровней архитектуры x86, возможно, также включающий набор данных CPUID для нескольких реальных моделей CPU, и удобный для пользователя метод конфигурации для выбора одной из них для виртуальной машины

==== Изменения за последний квартал

===== Изменения в синтаксисе конфигурации bhyve

В последний момент произошло изменение синтаксиса конфигурации.
Вместо использования двух разных опций `cpuid.enable` и `cpuid.disable` для включения или отключения функций по имени, теперь есть единая опция `cpuid.features`.
Эта опция принимает имя функции, либо с префиксом `-` для их отключения, либо с префиксом `+` или без префикса для включения функции.

===== Предопределённые модели CPU

В дополнение к абстрактным моделям архитектуры x86, ряд моделей CPU был реализован в виде предопределённых фрагментов конфигурационных файлов.
В настоящее время это заканчивается поколением Icelake для Intel и поколением Bulldozer для AMD.

Введено множество дополнительных опций конфигурации cpuid для упрощения написания конфигураций моделей CPU, таких как `cpuid.brand` для строки бренда CPU или `cpuid.vendor` для переопределения идентификации производителя.

===== Проверки ограничений CPUID

Проверки ограничений были расширены, чтобы позволить определять битовые маски для значений, которые могут быть только численно понижены.

Введена новая опция конфигурации `cpuid.check` для переопределения действия по умолчанию в отношении проверок ограничений.
Она принимает значения `fail` (по умолчанию), `warn`, `none` и `fix`.

===== Конфигурация кэша

Конфигурации кэша по умолчанию были добавлены в модели архитектуры x86 и во все предопределённые модели CPU.

===== Идентификация гипервизора

Новая опция `cpuid.hypervisor` позволяет легко переопределить идентификацию гипервизора в функции CPUID 0x40000000.
Реальная идентификация гипервизора и флаги функций по-прежнему могут быть запрошены гостями из функции CPUID 0x40000100.
