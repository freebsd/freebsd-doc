=== Внедрение -fbounds-safety в стек TCP/IP ядра FreeBSD

Ссылки: +
link:https://wiki.freebsd.org/BoundsSafety[Страница вики] URL: link:https://wiki.freebsd.org/BoundsSafety[] +
link:https://freebsdfoundation.org/project/adopt-fbounds-safety-in-the-freebsd-kernel-tcp-ip-stack/[Страница проекта] URL: link:https://freebsdfoundation.org/project/adopt-fbounds-safety-in-the-freebsd-kernel-tcp-ip-stack/[]

Контакт: Abhijeet Sharma <abhijeetsharma2002@gmail.com>

Флаг -fbounds-safety в Clang позволяет коду на C указывать длину буфера, как в `+__counted_by(len)+`.
Затем компилятор проверяет обращения через этот указатель.
Обращение за границы диапазона вызывает срабатывание вместо повреждения памяти.
Стек TCP/IP разбирает недоверенный сетевой ввод, поэтому это хорошее место для начала.
Этот проект добавляет макросы и поддержку сборки, затем преобразует файлы TCP по одному.
Без этого флага аннотации разворачиваются в пустоту.
Дерево по-прежнему собирается с компилятором базовой системы и с GCC.

==== Этот квартал

* Внешний инструментарий собирает GENERIC на amd64, рецепт на вики.
* Макросы, параметр сборки и программные ловушки опубликованы, четыре рецензии приняты.
* `tcp_ecn.c` работает с проверками, ядро загружается и проходит тесты netinet.
* RFC по аксессору mbuf на arch@ и net@, обсуждение продолжается.
