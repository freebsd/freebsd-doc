=== Улучшения обнаружения и диагностики систем хранения

Контакт: Warner Losh <imp@FreeBSD.org>

Несколько изменений в этом квартале сделали обнаружение устройств хранения более удобным для наблюдения и диагностики, особенно во время загрузки.

Провайдер DTrace CAM получил пробы для ошибок ввода-вывода периферийных устройств, восстановления после ошибок и аннулирования периферийных устройств.
Дополнительные пробы сообщают, когда CAM удерживает или освобождает процесс загрузки и когда регистрируется новая шина.
Вместе эти пробы охватывают гораздо большую часть пути от начального обнаружения шины до создания дисковых периферийных устройств.
Их также можно использовать с анонимной трассировкой DTrace для исследования проблем, возникающих до того, как система достигнет многопользовательского режима.
Новые пробы документированы в man:dtrace_cam[4].

CAM теперь отправляет уведомление man:devctl[4], когда периферийное устройство аннулируется.
Уведомление включает серийный номер устройства, когда он доступен, или в противном случае его путь CAM, чтобы программное обеспечение управления системой могло идентифицировать исчезнувшее устройство.
Общий код, используемый для построения уведомлений CAM, был выделен для поддержки этого и будущих типов событий.

Два исправления улучшили обработку дисков, которые отказывают во время проверки.
CAM теперь прекращает проверку после аннулирования периферийного устройства вместо отправки дополнительных команд заброшенному устройству, где они могли вызвать длительные тайм-ауты и запутанные ошибки.
Было исправлено связанное условие для определения того, когда аннулировать диск.
Ошибки, сообщаемые для дисков NVMe через периферийное устройство CAM `nda`, теперь идентифицируют набор команд, что упрощает интерпретацию кодов операций команд.

man:mpsutil[8] получил команду `show discovery`, которая выводит таблицы обнаружения контроллера.
Это раскрывает представление контроллера о подключённых устройствах SAS и экспандерах и полезно при диагностике устройств, которые отсутствуют или подключены через неожиданный путь.

Наконец, man:nvmecontrol[8] получил исправления корректности для данных Autonomous Power State Transition.
Значения переходов теперь кодируются без промежуточного целочисленного переполнения, а данные идентификации, сообщающие чрезмерное число состояний питания, обрабатываются с помощью проверки границ вместо утверждения.
