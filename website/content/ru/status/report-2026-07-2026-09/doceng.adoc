=== Команда документационной инженерии

Ссылки: +
link:https://docs.freebsd.org/[Портал проекта документации] URL: link:https://docs.freebsd.org/[] +
link:https://docs.freebsd.org/en/books/fdp-primer/[Руководство по проекту документации для новых участников] URL: link:https://docs.freebsd.org/en/books/fdp-primer/[] +
link:https://www.freebsd.org/administration/#t-doceng[Команда документационной инженерии] URL: link:https://www.freebsd.org/administration/#t-doceng[]

Контакт: Documentation Engineering Team <doceng@FreeBSD.org>

Команда документационной инженерии отвечает за определение целей документации для коммиттеров проекта документации и контроль за их выполнением.
Устав команды doceng подробно описывает обязанности и сферу ответственности команды документационной инженерии.

В этом квартале в проекте документации, помимо текущего сопровождения, несколько проектов были завершены или находились в работе:

* {dch} добавил link:{handbook}containers[главу об OCI-контейнерах] в Handbook.
* {bcr} и {carlavilla} обновили link:{handbook}zfs[главу о ZFS] в Handbook.
* {dbaio} улучшил примеры в handbook, добавив кнопку копирования, которая опускает приглашение оболочки.
* {dbaio} обновил package:textproc/po4a[], инструментарий перевода, до версии 0.74.
* {alven} обновил package:textproc/groff[], инструментарий GNU для страниц руководства, до версии 1.24.2.
* {fernape} обновил package:www/gohugo[], генератор сайта, до версии 1.76.0.
* {wosch} обновил link:https://man.FreeBSD.org[man.FreeBSD.org], старейший и крупнейший архив страниц руководства в интернете.
* {ziaee} обновил link:{fdp-primer}manual-pages/#manual-pages-sample-structures-section-4[руководящие указания для руководств по драйверам устройств]; приведение всех руководств к этому формату продолжается.
* {ziaee} улучшает совместимость страниц руководства с предстоящей версией package:textproc/mandoc[] 1.15.
* {vladlen} и {carlavilla} вложили значительную работу в корректность кода веб-сайта проекта.
* {vladlen} и {andy} усердно работали над поддержанием актуальности русского перевода.

В этом квартале {vladlen} был повышен до doc commit bit.
Другие commit bit в этом квартале не выдавались и не изымались на хранение.
