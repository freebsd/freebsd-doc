=== Пользовательские утилиты ext2fs

Ссылки: +
link:https://github.com/realchonk/freebsd-src/tree/ext2fs-user-tools[Рабочая ветка] URL: link:https://github.com/realchonk/freebsd-src/tree/ext2fs-user-tools[]

Контакт: Benjamin Stürz <benni@FreeBSD.org>

Цель этого проекта — реализовать утилиты для управления файловыми системами ext2fs в базовой системе FreeBSD.

Проект включает следующее:
- man:dumpfs_ext2fs[8]
- man:newfs_ext2fs[8]
- man:fsck_ext2fs[8]
- man:tunefs_ext2fs[8]
- libext2fs (та же идея, что и libufs)
- интеграция в makefs
- тесты для упомянутых компонентов

Спонсор: Фонд FreeBSD
