=== Серия улучшений IPv6

Контакт: Pouria Mousavizadeh Tehrani <pouria@FreeBSD.org>

С момента последнего отчёта я продолжал обновлять наш стек IPv6 и реализовывать ожидающие RFC, и результаты теперь доступны в CURRENT.

На данный момент я добавил поддержку:

* RFC 8925: Опция предпочтения IPv6-only в man:dhclient[8].
Когда опция получена и доступно подключение по IPv6, dhclient останавливает конфигурацию DHCPv4, освобождает предыдущую аренду и ждёт в течение срока, указанного сервером, прежде чем возобновить обнаружение.
Для проверки подключения по IPv6 используется Netlink.
link:https://reviews.freebsd.org/D56637[(D56637)]
* RFC 6275 (раздел 8.3) и RFC 9762 (раздел 7.1): Биты R и P опции информации о префиксе теперь предоставляются пользовательскому пространству для будущих реализаций.
link:https://reviews.freebsd.org/D56207[(D56207)]

Я также исправил несколько ошибок в стеке:

* Временные адреса RFC 8981 регенерировались для отсоединённых префиксов.
link:https://reviews.freebsd.org/D60051[(D60051)]
* Индекс исходящего интерфейса pktinfo проверялся по неверному интерфейсу в кэше маршрутов, согласно RFC 3542, раздел 6.
link:https://reviews.freebsd.org/D58544[(D58544)]
* Неверные сообщения о несовместимости флагов RA в man:rtadvd[8].
link:https://reviews.freebsd.org/D58672[(D58672)]

Ведущаяся работа:

* RFC 4429: Добавление поддержки Optimistic DAD.
link:https://reviews.freebsd.org/D55229[(D55229)]
