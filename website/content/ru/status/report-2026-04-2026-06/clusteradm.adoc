=== Команда администраторов кластера

Ссылки: +
link:https://www.freebsd.org/administration/#t-clusteradm[Участники команды администраторов кластера] URL: link:https://www.freebsd.org/administration/#t-clusteradm[]

Контактное лицо: Команда администраторов кластера <clusteradm@FreeBSD.org> +
Контактное лицо: Philip Paeps <philip@FreeBSD.org>

Члены команды администраторов кластера FreeBSD отвечают за управление машинами, на которые полагается Проект для синхронизации своей распределённой работы и коммуникаций.

В этом квартале команда работала над следующим:

* Обычная поддержка учётных записей пользователей FreeBSD.org.
* Обычная поддержка дисков и комплектующих (и их замена) для всех физических хостов и зеркал.
* Обновление программного обеспечения кластера.
* Координация работы сообщества зеркал.
* Дополнительная поддержка команды wiki-admin@.
* Частые вмешательства для предотвращения атак типа "отказ в обслуживании" со стороны ботов.

==== Обновление кластера

Продолжается работа по обновлению программного обеспечения, работающего на машинах кластера FreeBSD.org.
Мы начали размещать рабочие нагрузки на stable/15.
В рамках этой работы некоторые рабочие нагрузки переносятся на разные машины.
Эта работа продолжается на конец квартала.

Команда clusteradm обновляет рабочие сборщики пакетов (около 35 физических машин) с периодичностью примерно раз в шесть-восемь недель.
На этих машинах работают снимки current ветки FreeBSD.

Другие машины обновляются по мере необходимости, с учётом исправлений безопасности в зависимости от степени их доступности извне.

На момент написания этого отчёта в кластере насчитывается 142 физические машины.
У нас 42 машины на current, 21 на stable/15 и 73 на stable/14.

Большинство оставшихся установок stable/13 будут обновлены до stable/15.

==== Поддержка команды wiki-admin@

Команда администраторов кластера взяла на себя роль wiki-admin на протяжении большей части этого квартала, пока должность была вакантна.
Недавно была назначена новая команда wiki-admin.
Команда администраторов кластера продолжает поддерживать команду wiki-admin в необходимых обновлениях внутренней инфраструктуры вики.

==== Сбор данных для больших языковых моделей

Инфраструктура Проекта FreeBSD продолжает подвергаться постоянным атакам со стороны сборщиков данных для обучения больших языковых моделей («ИИ»).
Компании, обучающие эти модели, в значительной степени перенесли операции по сбору данных со своей собственной — легко идентифицируемой — инфраструктуры на ботнеты («резидентные прокси»), что затрудняет их блокировку на сетевых границах без значительного сопутствующего ущерба.
Команда администраторов кластера снова потратила значительное количество времени в этом квартале на смягчение этих распределённых атак типа «отказ в обслуживании».
