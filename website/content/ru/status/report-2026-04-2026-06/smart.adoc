=== Нативное получение данных S.M.A.R.T. во FreeBSD

Ссылки: +
link:https://github.com/ctuffli/smart[S.M.A.R.T. на GitHub] URL: link:https://github.com/ctuffli/smart[]

Контактное лицо: Chuck Tuffli <chuck@freebsd.org>

Во FreeBSD в базовую систему импортирована нативная утилита Self-Monitoring, Analysis, and Reporting Technology (S.M.A.R.T.) — man:smart[8], обеспечивающая лёгкие встроенные возможности мониторинга состояния дисков без необходимости установки сторонних пакетов.
Она была вдохновлена фреймворком man:diskctl[8], предложенным на AsiaBSDCon 2016, для создания свободно лицензируемой утилиты S.M.A.R.T., устраняющей проблемы с лицензированием и пробелы в функциональности существующих инструментов.

Утилита предоставляет унифицированный интерфейс для получения данных S.M.A.R.T. через несколько протоколов хранения, включая ATA, NVMe и SCSI.
Она ориентирована на лёгкость интеграции с инструментами мониторинга, поддерживая несколько форматов вывода (поля с разделителями табуляции, JSON, XML) через man:libxo[3] и позволяя пользователям запрашивать конкретные атрибуты состояния.
