=== Улучшение OpenJDK во FreeBSD

Цель этого проекта — улучшить поддержку OpenJDK для FreeBSD/amd64 и FreeBSD/arm64.

Java является важной средой выполнения для многих высокопроизводительных критически важных корпоративных систем.
Обеспечение корректной и эффективной работы приложений на основе Java во FreeBSD важно для того, чтобы FreeBSD оставалась жизнеспособной и привлекательной платформой для предприятий, а также бизнеса и организаций всех размеров.

Этот квартал был в основном потрачен на правильную организацию процесса отправки изменений в вышестоящие проекты.
Мы отправляем патчи в link:https://github.com/openjdk/bsd-port[отдельный репозиторий] в организации OpenJDK на Github и следим за тем, чтобы каждый PR был проверен по крайней мере одним рецензентом из вышестоящего проекта.
Таким образом, когда мы дойдём до момента, когда захотим включить наш порт в основную ветку вышестоящего проекта, все коммиты уже должны быть проверены кем-то из проекта.

Это довольно медленный процесс, поскольку мы зависим от наличия времени у рецензентов из вышестоящего проекта.
Мы также сталкиваемся с тем, что некоторые изменения, которые долго жили в нашем порту, отклоняются.
Тогда нам приходится переделывать их или, если они не строго необходимы, просто отбрасывать.
Я считаю, что это полезная корректировка, но иногда требует значительного объёма работы.
