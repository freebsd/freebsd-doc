=== FreeBSD в Microsoft HyperV и Azure

Ссылки: +

Контакт: Команда Microsoft FreeBSD Integration Services <bsdic@microsoft.com> +
Контакт: link:https://lists.freebsd.org/subscription/freebsd-cloud[Список рассылки freebsd-cloud] +

Контакт: Wei Hu <whu@FreeBSD.org>, <weh@microsoft.com> +
Контакт: Li-Wen Hsu <lwhsu@FreeBSD.org>

Публикация образа 15.1-RELEASE в Azure Marketplace находится в процессе.
Ожидается, что он станет общедоступным в начале третьего квартала.

Li-Wen изучает технические детали, необходимые для поддержки Azure Trusted Launch.

Wei и Li-Wen совместно с другими инженерами Microsoft исследуют проблему, из-за которой mana(4) некорректно работает на Azure-виртуальных машинах на базе AMD.
Устройство mana(4) присутствует на новейших виртуальных машинах Azure седьмого поколения.

Задачи в процессе выполнения:

* Автоматизация процесса публикации образов и интеграция его в [.filename]#src/release/#.
* Улучшение процесса публикации в Azure Marketplace.
* Поддержка FreeBSD в link:https://github.com/Azure/azure-vm-utils/[утилитах для виртуальных машин Azure].

Открытые задачи:

* Обновление документации, связанной с FreeBSD, на link:https://learn.microsoft.com[Microsoft Learn].
* Обновление пакета package:sysutils/azure-agent[] до последней версии.
* Перенос link:https://github.com/Azure/WALinuxAgent/pull/1892[локальных изменений агента Azure] в основной репозиторий.
* Перенос link:https://github.com/Azure/azure-linux-extensions[расширений для виртуальных машин Linux в Azure].
* Добавление поддержки FreeBSD в link:https://azure.microsoft.com/products/devops/pipelines/[Azure Pipelines].
** link:https://github.com/microsoft/azure-pipelines-agent/pull/3266[]
** Сборка и публикация снимков сборок (snapshot builds) в link:https://learn.microsoft.com/azure/virtual-machines/share-gallery-community[сообщество Azure].
