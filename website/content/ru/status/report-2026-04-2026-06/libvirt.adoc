=== Улучшение поддержки libvirt для гипервизора bhyve

Ссылки: +
link:https://libvirt.org/drvbhyve.html[libvirt: Драйвер bhyve] URL: link:https://libvirt.org/drvbhyve.html[] +

Контактное лицо: Roman Bogorodskiy <novel@FreeBSD.org>

==== Выполненные работы

* Драйвер libvirt/bhyve:
** Добавлена поддержка устройства `virtio-console`.
** Добавлена поддержка QEMU Guest Agent.
** Реализовано несколько функций на основе QEMU Guest Agent, таких как корректная перезагрузка и выключение, управление временем гостевой ОС, SSH-ключами, паролями пользователей и т.д.
** Добавлена настройка памяти и настройка ввода-вывода для блочных устройств на основе man:rctl[8].
* В процессе разработка по расширению CI libvirt для тестирования на снимках виртуальных машин FreeBSD-CURRENT.

==== Планы на следующий квартал

* Добавить поддержку настройки порядка загрузки.
* Добавить поддержку устройств TPM.
* Завершить поддержку приостановки/возобновления.
* Продолжить реализацию функций на основе QEMU Guest Agent.
* Продолжить расширение CI, охватив новые функции на основе гостевого агента новыми тестами.

Спонсор: The FreeBSD Foundation
