=== Dockerbox

Ссылки: +
link:https://github.com/leafoliage/freebsd-dockerbox[freebsd-dockerbox на Github] URL: link:https://github.com/leafoliage/freebsd-dockerbox[] +

Контактное лицо: Chun-Cheng Yeh <leafoliage@FreeBSD.org>

Dockerbox — это виртуализированный демон Docker.
Хотя демон Docker изначально недоступен во FreeBSD, Dockerbox запускает его внутри виртуальной машины Debian под управлением Bhyve, обеспечивая доступ к нему.
Dockerbox поддерживает обычные функции Docker, такие как Docker Compose, публикацию портов и привязку монтирований (bind mounts).
Этот проект направлен на упрощение использования Docker во FreeBSD в непроизводственных средах.

==== Связанные порты и репозитории

* link:https://github.com/leafoliage/freebsd-dockerbox[freebsd-dockerbox] +
Обеспечивает работу Docker во FreeBSD путём запуска `dockerd` внутри гостевой Linux-виртуальной машины Bhyve.
Эта служба управляет жизненным циклом гостевой системы Dockerbox, а также её сетевыми настройками и настройками хранилища. +
*v0.2.5 — портирован.*

* link:https://github.com/leafoliage/dockerbox-broker[dockerbox-broker] +
Дочерняя служба Dockerbox, которая обрабатывает перенаправление портов с хоста на гостевую систему Dockerbox, когда контейнер запрашивает публикацию портов. +
*Ещё не портирован.*

* link:https://github.com/leafoliage/freebsd-dockerbox-debian[freebsd-dockerbox-debian] +
Кодовая база, используемая для создания дискового образа Dockerbox. +
*Не портирован.*

* link:https://www.freshports.org/sysutils/docker-cli/[docker-cli] +
Инструмент командной строки Docker CLI. +
*v29.4.2 — портирован.*

* link:https://www.freshports.org/sysutils/docker-compose/[docker-compose] +
Плагин Docker CLI для определения и запуска многоконтейнерных приложений. +
*v5.1.3 — портирован.*

* link:https://www.freshports.org/sysutils/docker-buildx[docker-buildx] +
Плагин Docker CLI, предоставляющий расширенные возможности сборки через BuildKit. +
*v0.34.1 — портирован.*

Пакеты package:sysutils/dockerbox[], package:sysutils/docker-cli[], package:sysutils/docker-compose[] и package:sysutils/docker-buildx[] теперь доступны в Коллекции Портов FreeBSD и через `pkg`.
