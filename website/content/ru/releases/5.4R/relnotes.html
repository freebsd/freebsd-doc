Информация о релизе FreeBSD 5.4-RELEASE

Информация о релизе для FreeBSD публикуется отдельно для каждой платформы, поскольку многие изменения в FreeBSD выполняются только для определенной процессорной архитектуры.

Информация о релизе для FreeBSD 5.4-RELEASE доступна для следующих платформ:

  • alpha
  • amd64
  • i386
  • ia64
  • pc98
  • sparc64

Список всех платформ, находящихся в разработке, опубликован на странице Поддерживаемых платформ.
