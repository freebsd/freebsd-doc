=== Enhancing Zoned Storage support

==== Project Overview

Work on this project intends to enhance Zoned Storage support in FreeBSD, by adding the following new features:

* New man:gzoned[8] GEOM driver for emulating zoned devices.
* Zoned Namespaces (ZNS) support for zoned NVMe drives.
* Improved Zoned Storage handling for man:gconcat[8], man:glabel[8], and man:gpart[8].

The work was carried out as part of Google Summer of Code 2026.

==== Importance to FreeBSD

The new man:gzoned[8] driver emulates Zoned Storage on top of regular, non-zoned drives, allowing for development, testing, and integration of Zoned Storage without zoned hardware.

ZNS support enables using Zoned Storage on NVMe SSDs.

Zone-aware GEOM classes let host-managed drives be used with the usual storage tools.

==== Status

man:gzoned[8] is now in main.

ZNS support was added to the man:nda[4] driver, while man:nvd[4] support is not planned due to its barebones nature.

Host-managed devices can now be concatenated through man:gconcat[8], while man:glabel[8] will cleanly refuse them for automatic labeling due to its metadata requirement.
man:gpart[8] can now create GPT partition schemes on host-managed drives by not writing the backup GPT table.

==== Plans for next quarter

* Polish up man:gconcat[8], man:glabel[8], and ZNS support, as they can now rely on man:gzoned[8] from main.
* Merge the complete work into main.
