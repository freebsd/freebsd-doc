=== ext2fs user space tools

Links: +
link:https://github.com/realchonk/freebsd-src/tree/ext2fs-user-tools[Working branch] URL: link:https://github.com/realchonk/freebsd-src/tree/ext2fs-user-tools[]

Contact: Benjamin Stürz <benni@FreeBSD.org>

The goal of this project is to implement tools for managing ext2fs filesystems in base FreeBSD.

The project includes the following:
- man:dumpfs_ext2fs[8]
- man:newfs_ext2fs[8]
- man:fsck_ext2fs[8]
- man:tunefs_ext2fs[8]
- libext2fs (same idea as libufs)
- integration into makefs
- tests for the mentioned components

Sponsor: The FreeBSD Foundation
