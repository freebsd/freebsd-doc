=== LLDB Improvement on FreeBSD

Contact: Minsoo Choo <mchoo@FreeBSD.org>

I was off for university from May to August and I'm back to working on this now.
Since I couldn't accomplish this task for LLVM 23, the target release for completion has changed to LLVM 24.

armv7 and powerpc64be are support candidates now. Once LLDB refactoring is done, I will implement support for those architectures.

Unlike KGDB that uses custom frame sniffer for trapframe unwinding, LLDB uses DWARF CFI instead.
DWARF CFI works on KGDB as well; when a frame is not recognized by KGDB's frame sniffer, it will fall back to CFI.
Thus, no change on the KGDB side is needed.
