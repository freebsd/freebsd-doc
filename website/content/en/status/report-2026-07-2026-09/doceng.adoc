The Documentation Engineering Team is responsible for defining and following up documentation goals for the committers in the Documentation Project.
The doceng team charter describes the duties and responsibilities of the Documentation Engineering Team in greater detail.

This quarter in the Documentation Project, in addition to routine maintenance, several projects have come to fruition or were underway:

* {dch} added an link:{handbook}containers[OCI container chapter] to the Handbook.
* {bcr} and {carlavilla} refreshed the link:{handbook}zfs[ZFS chapter] of the Handbook.
* {dbaio} improved handbook examples to have a clickable copy button which omits the shell prompt.
* {dbaio} updated package:textproc/po4a[], the translation toolchain, to version 0.74.
* {alven} updated package:textproc/groff[], the GNU manual page toolchain, to version 1.24.2.
* {fernape} updated package:www/gohugo[], the website generator, to version 1.76.0.
* {wosch} updated link:https://man.FreeBSD.org[man.FreeBSD.org], the oldest and largest manual pages archive on the internet.
* {ziaee} updated the link:{fdp-primer}manual-pages/#manual-pages-sample-structures-section-4[guidelines for device driver manuals], updating all manuals to this format is underway.
* {ziaee} is improving manual page compatibility for the upcoming package:textproc/mandoc[] version 1.15.
* {vladlen} and {carlavilla} have invested considerable work in code-correctness for the Project website.
* {vladlen} and {andy} have been hard at work keeping the Russian translation up to date.

This quarter, {vladlen} was promoted to a doc commit bit.
No other commit bits have been granted or taken in for safekeeping during this quarter.
