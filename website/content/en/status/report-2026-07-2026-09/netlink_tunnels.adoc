=== Netlink Support for Tunnel Interfaces

Contact: Pouria Mousavizadeh Tehrani <pouria@FreeBSD.org>

Following the man:geneve[4] work, I have been migrating our other tunnel drivers to the new if_clone KPI and adding netlink support for them, both in kernel and in man:ifconfig[8].
They are now available on CURRENT.

So far, I have added the support for:

* Netlink support for man:gif[4] with tests.
link:https://reviews.freebsd.org/D57666[(D57666)]
* Netlink support for man:gre[4] with a regression test.
link:https://reviews.freebsd.org/D55366[(D55366)]
* IFLAF_GROUP, a FreeBSD-specific netlink attribute to carry the interface groups, since IFLA_GROUP only works with a single numeric group id.
man:ifconfig[8] now reads the interface groups from it.
link:https://reviews.freebsd.org/D58643[(D58643)]

While here, I fixed the following bugs:

* Races during man:gre[4] module initialization and destruction of cloned interfaces in jails.
link:https://reviews.freebsd.org/D57669[(D57669)]
* Panic in man:vxlan[4] when unused drvspec values are passed.
link:https://reviews.freebsd.org/D58552[(D58552)]
* Wrong interface name translation in Linux netlink dumps under man:linux[4], and mapping of more interface types to ARPHRD.
link:https://reviews.freebsd.org/D59595[(D59595)]

Ongoing work:

* Full support for GRE key.
link:https://reviews.freebsd.org/D59849[(D59849)]
