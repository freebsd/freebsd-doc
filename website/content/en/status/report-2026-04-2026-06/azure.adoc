Publishing the 15.1-RELEASE image to Azure Marketplace is in progress.
It is expected to become publicly available early in the third quarter.

Li-Wen is investigating the technical details needed to support Azure Trusted Launch.

Wei and Li-Wen, together with other Microsoft engineers, are investigating an issue preventing mana(4) from working correctly on AMD-based Azure VMs.
The mana(4) device is present on the latest v7-generation Azure VMs.
